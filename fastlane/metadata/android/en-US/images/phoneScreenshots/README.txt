Screenshots go here, captured on a real device.

Shizuku needs a real device, so an emulator cannot show this app in a working
state - a screenshot taken there would show only the "Shizuku not available"
state, which misrepresents the app.

Naming: F-Droid and IzzyOnDroid order screenshots by filename, so use a numeric
prefix - 1.png, 2.png, 3.png. PNG or JPEG, portrait, at the device's native
resolution. Four to six is plenty; the first one is the one users see in the
list, so lead with the app list showing several apps and their states.

Do not include screenshots showing real personal data - the app list shows every
installed app on the device it was captured from.

Delete this file once real screenshots are in place.
